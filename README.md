# Чьё музло?! 🎧🔥

Социальная пати-игра / музыкальная дедукция для компаний друзей.

**Приложение — это лобби-экран (как в Jackbox).** На нём нельзя играть или загружать треки: все игроки подключаются по ссылке-приглашению со своих телефонов. Экран лобби показывает код, QR и ссылку, играет музыку и ведёт раунды.

Работает в одной Wi-Fi, а с Cloudflare Tunnel — и с удалёнными игроками из любой сети.

## Как устроено

- **Локальный хост-сервер** (`server/`) раздаёт приложение и связывает лобби с игроками по WebSocket.
- **Лобби** (корень приложения) — код, QR, ссылка-приглашение, список игроков, плеер и управление раундами.
- **Игроки** открывают ссылку `...?code=XXXX` на телефонах, вводят ник, кидают треки и голосуют во время прослушивания.
- **Cloudflare Tunnel** (опционально) — публичная ссылка `*.trycloudflare.com` для удалённых игроков.

## Быстрый старт

```bash
npm install
npm run host          # лобби в локальной сети → http://localhost:8080
```

Для удалённых игроков (нужен `cloudflared`):

```bash
npm run host:tunnel
```

Подробности — [SETUP.md](SETUP.md).
