# Чьё музло?! 🎧🔥

Социальная парти-игра / музыкальная дедукция для компаний друзей.

**Комната запускается на одном устройстве** (компьютер/ноутбук), а остальные игроки подключаются **по ссылке в браузере** — как в Jackbox. Всё в одной Wi-Fi сети, без внешних сервисов и интернета.

## Как устроено

- **Локальный хост-сервер** (`server/`) раздаёт приложение и связывает хоста с гостями по WebSocket.
- **Хост** открывает `http://localhost:8080`, создаёт комнату, видит код + QR, играет музыку.
- **Гости** открывают `http://<LAN-IP>:8080` на телефонах, вводят код, кидают ссылки и голосуют.
- Синхронизация — WebSocket, всё в памяти сервера. Никаких аккаунтов и ключей.

## Быстрый старт

```bash
npm install
npm run host
```

В терминале будут адреса для хоста и гостей. Подробности — [SETUP.md](SETUP.md).

## Структура

```
Чьё музло/
├── README.md
├── SETUP.md                   # как запустить и играть
├── start.cmd                  # запуск в один клик (сервер + браузер)
├── launcher.ps1               # логика запуска
├── assets/muzlo.ico           # иконка ярлыка
├── docs/
│   ├── architecture.md        # стек, решения, схема WS-релея
│   └── technical-spec.md      # ТЗ (правила очков и т.д.)
├── server/
│   └── index.mjs              # локальный сервер: статика + WS-релей
├── shared/                    # чистая логика (npm workspace: @muzlo/shared)
│   └── src/
│       ├── scoring.ts         # правила очков
│       ├── comments.ts        # мемные комментарии
│       ├── links.ts           # парсер ссылок ЯМузыки
│       ├── game.ts            # движок игры
│       └── types.ts
└── app/                       # клиент (Vite + React)
    └── src/
        ├── App.tsx            # лендинг → хост / гость
        ├── sync.ts            # WebSocket-синхронизация
        ├── host/HostApp.tsx   # экраны хоста
        ├── guest/GuestApp.tsx # маршрутизация гостя
        └── pages/             # экраны гостя
```

> `app/android/` и `chyo-muzlo-debug.apk` — **устаревший путь** (нативное приложение). Новой модели не нужны: хост — это компьютер с локальным сервером, гости — браузеры.
