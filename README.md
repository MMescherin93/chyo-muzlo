# Чьё музло?! 🎧🔥

Социальная парти-игра / музыкальная дедукция для компаний друзей. **Одно приложение на всех**: хост создаёт комнату и играет музыку, гости подключаются по коду/QR со своих телефонов. Философия — «one-night stand»: прогресс между сессиями не сохраняется, только эмоции и смех здесь и сейчас.

## Как устроено

- **Одно приложение (PWA / APK)** — открывается в браузере или ставится на Android.
- **Синхронизация** — через публичные MQTT-брокеры. **Никаких аккаунтов, ключей и настроек** — запустил и играешь. Нужен только интернет.
- **Хост** — создаёт комнату, показывает QR + 4-значный код, играет треки (iframe Яндекс Музыки), ведёт раунды.
- **Гости** — открывают тот же адрес, вводят код, кидают ссылки на треки и голосуют.

## Быстрый старт

```bash
npm install
npm run dev      # http://localhost:5173
```

Или установи готовый **`chyo-muzlo-debug.apk`** из корня проекта.

Полная инструкция — [SETUP.md](SETUP.md).
