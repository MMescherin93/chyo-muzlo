# Запуск «Чьё музло?!»

Приложение — это **лобби-экран** (как в Jackbox): на нём нельзя играть или загружать треки. Все игроки подключаются **по ссылке-приглашению** со своих телефонов.

---

## 0. Что нужно

| Что | Зачем |
|-----|-------|
| **Node.js 18+** | запустить сервер |
| **Компьютер/ноутбук** | экран лобби + музыка |
| **Телефоны игроков** | открыть ссылку-приглашение |
| **Аккаунт Яндекс** | чтобы играли треки |
| **cloudflared** (опционально) | для удалённых игроков |

---

## 1. Локальная игра (одна Wi-Fi)

```bash
npm install
npm run host
```

Открой на компьютере **`http://localhost:8080`** — лобби создастся автоматически.

В терминале будет адрес для гостей в Wi-Fi (например `http://192.168.1.94:8080`). В лобби есть **код, QR и ссылка-приглашение** — гости открывают их на телефонах.

---

## 2. Удалённые игроки (Cloudflare Tunnel)

Публичный туннель даёт ссылку вида `https://xxx.trycloudflare.com` — по ней можно подключиться из любой сети.

**Один раз установить cloudflared:**

```powershell
winget install --id Cloudflare.cloudflared -e
```

**Запускать с туннелем:**

```bash
npm run host:tunnel
```

В терминале появится:

```
🌍 Публичная ссылка (Cloudflare Tunnel): https://xxx.trycloudflare.com
```

Лобби автоматически подхватит её и покажет в QR/ссылке (если открыто раньше — просто обнови страницу). Аккаунт Cloudflare не нужен — это Quick Tunnel.

### Вариант без команд: кнопка в лобби

Можно вообще не запускать `host:tunnel`. Открой лобби и нажми кнопку **«🌍 Публичная ссылка для удалённых»** под ссылкой-приглашением — сервер сам поднимет туннель (10–20 сек), и ссылка/QR автоматически обновятся на публичные.

> Если кнопка не появилась — на сервере старый процесс. Закрой окно сервера и запусти `npm run host` заново.

---

## 3. Как играть

1. **Экран лобби** показывает код, QR и ссылку-приглашение.
2. **Все игроки** (включая человека за компьютером, если он хочет играть) открывают ссылку на своих телефонах и вводят ник. Хост игроком **не является** и треки **не загружает**.
3. Каждый игрок кидает ссылки на треки из Яндекс Музыки.
4. Хост выбирает длительность (15/30/60) и жмёт **«НАЧАТЬ ИГРУ»**.
5. Раунд: трек играет у хоста (плеером управляет только он), а игроки **голосуют во время прослушивания** — видно, кто уже проголосовал (✅), а кто нет (⏳).
6. Хост жмёт **«Показать результат»** → комментарий и очки.
7. **«Следующий трек →»** и так до финала. **«Завершить игру»** — в любой момент.

> Никаких автотаймеров: все переходы — по кнопкам хоста.

---

## 4. Тестирование на одном компьютере

1. **Вкладка 1:** `http://localhost:8080` — экран лобби.
2. **Вкладка 2:** ссылка-приглашение из лобби — игрок 1.
3. **Вкладка 3:** та же ссылка — игрок 2 (каждая вкладка = отдельный игрок).

Инкогнито не нужно: гостевое состояние хранится в `sessionStorage` (у каждой вкладки своё).

---

## 5. Режим разработки (hot reload)

```bash
# терминал 1 — сервер (WS + статика)
node server/index.mjs

# терминал 2 — Vite
npm run dev
```

Vite на `http://localhost:5173` проксирует `/api` и `/ws` на `localhost:8080`.

## 6. Частые проблемы

| Симптом | Что делать |
|---|---|
| «Не удалось создать комнату» | Запущен ли `npm run host`? Открыт ли `http://localhost:8080`? |
| Гости в Wi-Fi не открывают ссылку | Разреши Node.js в Firewall Windows; телефон в той же Wi-Fi. |
| Туннель не появился | `cloudflared` не в PATH. Проверь `cloudflared --version`, перезапусти терминал после установки. |
| Публичная ссылка не в лобби | Туннель поднимается ~10–20 сек; обнови страницу. |
| Два игрока в одной вкладке/браузере | Используй разные вкладки — у каждой свой `sessionStorage`. |
| Трек не играет | Нажми «Открыть трек в новой вкладке»; проверь вход в Яндекс. |
| Порт 8080 занят | `PORT=8081 npm run host` (Windows: `set PORT=8081 && npm run host`). |

## 7. Структура

- `server/index.mjs` — сервер: статика, WebSocket-релей, Cloudflare-туннель.
- `app/` — клиент: лобби-экран (`host/`) и игроки (`guest/`, `pages/`).
- `app/src/sync.ts` — WebSocket-синхронизация.
- `shared/` — логика: очки, комментарии, ссылки, движок.
