# Запуск «Чьё музло?!»

Приложение **одно** и работает сразу: никаких аккаунтов, ключей и настроек. Синхронизация — через публичный MQTT-брокер, нужен только интернет.

Два способа: **APK на Android** (проще всего) или **веб-версия в браузере**.

---

## 1. Вариант с APK (Android)

**Готовый файл:** `chyo-muzlo-debug.apk` в корне проекта.

1. Перекинь `chyo-muzlo-debug.apk` на телефон (USB / Telegram «Избранное» / облако).
2. Открой файл → разреши «Установка из неизвестных источников».
3. Открой приложение **«Чьё музло?!»** — и играй. Заполнять ничего не нужно.

> Нужен интернет: игра синхронизирует игроков через публичный брокер.

### Первый запуск (хост)

1. Нажми **«Создать игру»** → введи ник → выбери длительность (15/30/60 мин).
2. Появится **QR-код** и **4-значный код** комнаты.
3. Открой Яндекс Музыку в браузере/приложении и залогинься (нужно для воспроизведения треков).
4. Когда соберутся игроки и будут треки — жми **«ПОГНАЛИ»**.

### Гости

1. Открывают **то же приложение** (или ссылку, если пользуетесь веб-версией).
2. Жмут **«Войти по коду»** → вводят код и ник.
3. Кидают ссылки на треки в лобби.

---

## 2. Как сыграть партию

1. **Хост** создаёт комнату → видит QR/код.
2. **Гости** подключаются по коду, вводят ники.
3. Каждый кидает **ссылку на трек** из Яндекс Музыки (Поделиться → Скопировать ссылку). Можно вставить и текст вида «Название — Исполнитель» + ссылка — тогда в разгадке будет название.
4. **Хост** жмёт «ПОГНАЛИ» → в раунде нажимает **Play** в плеере. Звук слышит вся комната (телефон хоста — на колонку).
5. Через 15–30 сек открывается **голосование** — все выбирают, кто скинул трек.
6. **Разгадка**: обложка/название + мемный комментарий + очки.
7. **Финал**: итоговая таблица.

Правила очков — [docs/technical-spec.md](docs/technical-spec.md) §5.

## 3. Веб-версия (без APK)

```bash
npm install
npm run dev
```

Откроется `http://localhost:5173`. С телефона в той же Wi-Fi:

```bash
npm run dev -- --host
```

и открыть `http://<IP-компьютера>:5173`.

### Деплой (по желанию)

Собери `app/dist` и выложи на любой статический хостинг (Firebase Hosting / Netlify / Vercel / GitHub Pages):

```bash
npm run build
```

На Android можно «Добавить на главный экран» — будет как приложение.

## 4. Пересобрать APK самому

Нужны **JDK 21** и **Android SDK (platform 36, build-tools 36)**.

```bash
npm run build            # веб → app/dist
cd app && npx cap sync android
cd android && gradlew assembleDebug   # Windows: gradlew.bat assembleDebug
```

APK: `app/android/app/build/outputs/apk/debug/app-debug.apk`.

> ⚠️ Кириллица в пути ломает `gradlew.bat` на Windows. Собирай через ASCII-junction:
> ```cmd
> mklink /J C:\muzlo "C:\Users\<ты>\Documents\Чьё музло"
> cd C:\muzlo\app\android
> gradlew.bat assembleDebug
> ```

## 5. Частые проблемы

| Симптом | Что делать |
|---|---|
| «Комната не отвечает» | Проверь код; хост должен держать приложение открытым. Проверь интернет. |
| Долго «Подключение…» | Публичный MQTT-брокер может тормозить. Подожди/повтори. Список брокеров — `app/src/sync.ts`. |
| Трек не играет | Нажми Play вручную; проверь вход в Яндекс Музыку; ссылка «Открыть в Яндекс Музыке» как fallback. |
| Гость не видит комнату | Код введён с опечаткой; хост создал комнату в другом приложении/вкладке. |
| Пустая страница в вебе | Не выполнен `npm install` или `npm run build`. |

## 6. Где что лежит

- `app/` — единое приложение (React + Vite + Capacitor).
- `app/src/sync.ts` — синхронизация через MQTT (список брокеров, логика хоста/гостя).
- `shared/` — чистая логика: очки, комментарии, разбор ссылок, движок.
- `chyo-muzlo-debug.apk` — собранный APK.
