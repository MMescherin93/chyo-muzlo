# Запуск «Чьё музло?!»

Теперь комната **запускается на одном устройстве** (компьютер/ноутбук), а гости подключаются **по ссылке в браузере**. Всё в одной Wi-Fi сети, интернет и внешние сервисы не нужны.

---

## 0. Что нужно

| Что | Зачем |
|-----|-------|
| **Node.js 18+** | запустить локальный хост-сервер |
| **Компьютер/ноутбук** | это «хост» — на нём запускается комната и играет музыка |
| **Телефоны гостей** | открыть ссылку в браузере, в той же Wi-Fi |
| **Аккаунт Яндекс** | чтобы в браузере хоста играли треки |

---

## 1. Быстрый старт

```bash
npm install
npm run host
```

В терминале появятся два адреса:

```
Хост (это устройство):  http://localhost:8080
Гости (по ссылке):      http://192.168.1.94:8080
```

1. **Хост** открывает `http://localhost:8080` в браузере на этом же компьютере.
2. **Гости** открывают второй адрес (`http://192.168.1.94:8080`) в браузере на телефонах — или сканируют QR, который покажет хост (он уже ведёт на правильный LAN-адрес).

> Компьютер и телефоны должны быть в одной Wi-Fi сети. Если адрес не открывается — проверь, что не блокирует Windows Firewall (разреши Node.js).

### Ярлык на рабочем столе

На рабочем столе создан ярлык **«Чьё музло»**. Двойной клик:
1. запускает `npm run host` в отдельном окне (сборка + сервер);
2. ждёт, пока сервер поднимется, и **сам открывает браузер** на `http://localhost:8080`.

В репозитории за это отвечает `start.cmd` → `launcher.ps1` (ярлык можно создать заново для любой папки).

## 2. Как сыграть партию

1. **Хост** нажимает «Создать игру» → вводит ник, длительность.
2. Появляется **4-значный код** и QR. Гости входят по коду/QR. Ссылку для гостей можно скопировать кнопкой **«📋 Скопировать ссылку»**.
3. Каждый кидает **ссылку на трек** из Яндекс Музыки. Хост тоже может добавить свой трек.
4. Хост жмёт **«ПОГНАЛИ»**. На раунде:
   - встроенный плеер Яндекс Музыки (или кнопка «Открыть трек в новой вкладке»);
   - нажми **Play**, звук идёт из колонок компьютера — слышит вся комната;
   - когда трек прослушан — **«Хватит слушать → к голосованию»** (или подожди автотаймер).
5. **Голосование** — все выбирают, кто скинул трек.
6. **Разгадка**: название, мемный комментарий, очки.
7. **Финал**: таблица. Хост может **завершить игру для всех** в любой момент.

Экран хоста не гаснет (wake-lock). Выйти из лобби можно кнопкой «Выйти».

---

## 3. Как тестировать на одном компьютере

Сервер запущен (`npm run host`), дальше — просто вкладки браузера:

1. Вкладка 1: `http://localhost:8080` → **«Создать игру»** (это хост).
2. Вкладка 2 (или окно инкогнито): `http://localhost:8080` → **«Войти по коду»** (это гость).
3. Ещё вкладки — ещё гости.

Никаких телефонов и внешних сервисов. Всё в одной машине.

---

## 4. Dev-режим (быстрые правки, hot reload)

Нужны два терминала:

```bash
# терминал 1 — хост-сервер (WS-релей)
node server/index.mjs

# терминал 2 — Vite с hot reload
npm run dev
```

Vite проксирует `/api` и `/ws` на `localhost:8080`. Открывай `http://localhost:5173`.

Если не нужен hot reload — достаточно `npm run host` (сам соберёт и запустит).

## 5. Про плеер

- Плеер Яндекс Музыки **встроен прямо в страницу** — официальный виджет `music.yandex.ru/iframe/`. Работает для любой ссылки на трек: `#track/{id}` или `#track/{id}/{album}`.
- Если виджет не играет (регион, браузер, вход в Яндекс) — есть кнопка **«▶ Открыть трек в новой вкладке»**.
- Без входа в Яндекс играет 30-секундный превью — для игры этого достаточно; с входом/подпиской — полный трек.
- Длительность раунда контролирует хост кнопкой **«Хватит слушать → к голосованию»** (или автотаймер).

## 6. Частые проблемы

| Симптом | Что делать |
|---|---|
| `npm run host` пишет «Сначала соберите приложение» | Запусти `npm run build`, затем снова `npm run host`. |
| Гости не открывают ссылку | Телефон и компьютер в одной Wi-Fi; разреши Node.js в Firewall Windows. |
| «Не удалось подключиться к комнате» | Проверь, что `npm run host` запущен и вкладка открыта с того же адреса/порта. |
| Хост открыл `localhost`, гости не могут | Хост должен сам открыть `localhost`, а гостям дать адрес из строки «Гости» (LAN-IP). QR делает это автоматически. |
| Трек не играет | Нажми «Открыть трек в новой вкладке» и Play; проверь вход в Яндекс. |
| Порт 8080 занят | `PORT=8081 npm run host` (Windows: `set PORT=8081 && npm run host`). |

## 7. Структура

- `server/index.mjs` — локальный сервер: раздаёт приложение и держит WS-релей.
- `app/` — клиент (React + Vite): экраны хоста и гостя, `app/src/sync.ts` — WebSocket.
- `shared/` — чистая логика: очки, комментарии, разбор ссылок, движок.
- `chyo-muzlo-debug.apk` — устаревший путь (APK). Новая модель его не требует.
