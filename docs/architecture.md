# Архитектура «Чьё музло?!» — лобби + игроки

## 1. Стек

| Слой | Технология | Почему |
|------|-----------|--------|
| **Хост-сервер** | **Node.js + `ws`** (`server/index.mjs`) | Раздаёт приложение, держит WebSocket-релей и (опционально) туннель Cloudflare. |
| **Клиент** | **Vite + React + TypeScript** | Один код: корень — лобби-экран, `?code=` — игрок. |
| **Логика** | `@muzlo/shared` (чистый TS) | Очки, комментарии, разбор ссылок, движок. Выполняется в браузере лобби. |
| **Музыка** | iframe Яндекс Музыки + ссылка в новую вкладку | Плеером управляет только лобби. |
| **Туннель** | **cloudflared Quick Tunnel** | Публичная HTTPS-ссылка `*.trycloudflare.com` для удалённых игроков, без аккаунта. |
| **Хранение** | память сервера | «One-night stand»: комната живёт только пока запущен сервер. |

## 2. Ключевые решения

1. **Приложение — это лобби (как в Jackbox).** Корень (`/`) — экран лобби: код, QR, ссылка, плеер и управление раундами. **Хост не является игроком** и не загружает треки.
2. **Все игроки — по ссылке.** Игрок попадает в режим игры только по `/?code=XXXX`; его состояние (uid, ник, комната) хранится в `sessionStorage` — каждая вкладка/устройство = отдельный игрок.
3. **Хост — авторитет.** `GameEngine` живёт в браузере лобби; сервер — тонкий релей.
4. **Локальная сеть + опциональный туннель.** `npm run host` — Wi-Fi; `npm run host:tunnel` — публичная ссылка Cloudflare для удалённых.
5. **Только ссылки на треки**, звук только у лобби.

## 3. Поток данных (WebSocket-релей)

```
      ┌────────────── server/index.mjs ──────────────┐
      │  rooms: { host, guests:Set, state }           │
      └───────▲───────────────────────────┬──────────┘
              │ state                     │ state
              │                           │
        ┌─────┴─────┐               ┌─────▼─────┐
        │  Лобби    │               │  Игроки   │
        │ GameEngine│               │  UI       │
        └─────┬─────┘               └─────▲─────┘
              │ intent                    │
              └───────────────────────────┘
```

Протокол (JSON по `/ws`):

| От | Сообщение | Смысл |
|---|---|---|
| Лобби | `{t:'host', room}` | зарегистрироваться хостом комнаты |
| Игрок | `{t:'guest', room}` | войти в комнату; сервер сразу шлёт последнее `state` |
| Лобби | `{t:'state', room, data}` | опубликовать снимок комнаты (кэшируется и рассылается игрокам) |
| Игрок | `{t:'intent', data}` | намерение: `join` / `track` / `vote` |
| Сервер | `{t:'state', data}` | игрокам |
| Сервер | `{t:'intent', data}` | лобби |
| Сервер | `{t:'host-gone'}` | игрокам, если лобби отключилось |

- **Лобби** держит `GameEngine`, ведёт фазы и рассылает `state`. Лобби не является игроком.
- **Игроки** читают `state` и шлют `intent`.
- **Поздний игрок** сразу получает последнее состояние — сервер его кэширует.

## 4. Переходы раунда (только кнопками лобби)

```
start() → beginRound: идёт прослушивание, голосование уже открыто
   └─ кнопка «Показать результат» → reveal()   (очки + комментарий)
         └─ кнопка «Следующий трек» → nextRound()  (или finish)
```

Автотаймеров нет. Голосовать можно во время `playing`. В состоянии публикуется
`votedIds` — кто уже проголосовал (✅), а кто нет (⏳).

## 5. Локальная сеть, QR и Cloudflare Tunnel

- Сервер слушает `0.0.0.0:8080`.
- `GET /api/info` возвращает:
  - `origin` — LAN-адрес (`http://192.168.x.x:8080`);
  - `publicOrigin` — публичный `https://*.trycloudflare.com`, если запущен туннель.
- Лобби берёт `publicOrigin` (если есть), иначе `origin`, и строит из него QR/ссылку. `/api/info` переопрашивается раз в 3 сек, поэтому ссылка появляется, когда туннель поднимется.
- `npm run host:tunnel` → `server/index.mjs --tunnel` → `spawn('cloudflared', ['tunnel','--url','http://127.0.0.1:8080','--no-autoupdate'])`; URL парсится из вывода cloudflared.
- Туннель — Quick Tunnel: без аккаунта, HTTPS, поддерживает WebSocket.

## 7. Ограничения

- **Плеер Яндекс Музыки** — iframe работает нестабильно; есть кнопка «Открыть в новой вкладке». Полные треки — при входе в Яндекс (иначе 30-сек превью).
- **Случайная точка трека** недоступна (нет API).
- **Компьютер с лобби должен держать сервер запущенным** — он и есть комната.
- **Quick Tunnel** — бесплатный и без аккаунта, но URL меняется при каждом запуске и сервис не гарантирует SLA.
- `app/android/` и APK — **устаревший путь**, новой модели не нужны.
